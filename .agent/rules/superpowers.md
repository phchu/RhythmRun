# Superpowers Rules (Always-On)

These rules apply to ALL work in this project.

## 1. Plan Before Coding
If the task is beyond a tiny change, do NOT edit code immediately.
1. Brainstorm briefly.
2. Write a step-by-step plan.
3. Ask the user to approve the plan.
Only implement after approval.

## 2. Verification is Mandatory
After implementation, provide exact commands to verify (tests/lint/run) and the results.

## 3. Artifact Persistence
Important outputs (plans, brainstorms, execution logs, summaries) must be saved to the `artifacts/superpowers/` directory.

## 4. Review Required
Before finishing a major task, perform a self-review or use a review skill.
